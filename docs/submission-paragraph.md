> Kane Loop is a veto gate for AI coding agents, built with Muse for developers who use an agent to write code and want proof — not a promise — that it works. A watcher any agent can install in one command blocks on a diff, not on a claim: `kane-watch` fires Kane CLI on every save, parses the NDJSON run, and only a separate verifier process can write `LOOP_VERIFIED`, after replaying the committed `_test.md` suite and running a fresh independent chaos sweep in which Kane derives the expected total itself. Its demo victim is LoopMart, a tiny no-login checkout (Loop Mug £15, Debug Hoodie £35, Kane Notebook £10) where a double-click on Pay charges the same order twice — so a failure is a visible ledger error, not a missing class.
